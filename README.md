# Kiazo.tr - Modern Software Studio Landing Page

A premium, dark-themed landing page for Kiazo, a Turkish software agency that builds modern web and mobile applications.

## Features

- **Modern Dark Theme** - Elegant dark mode with blue/purple gradient accents
- **Smooth Animations** - Powered by Framer Motion for fluid, professional animations
- **Fully Responsive** - Optimized for desktop, tablet, and mobile devices
- **Glassmorphism Design** - Modern UI with backdrop blur and gradient effects
- **Single Page** - Clean, scrollable one-page layout

## Tech Stack

- **React 18** - Modern React with TypeScript
- **Vite** - Fast build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Production-ready animation library
- **TypeScript** - Type-safe development

## Sections

1. **Hero** - Eye-catching headline with animated particles
2. **Technologies** - Showcase of tech stack (PHP, Laravel, Vue, React, Flutter, Swift)
3. **Capabilities** - What we build (Web Apps, Mobile Apps, AI & Automation)
4. **About** - Company information and location
5. **Contact** - Email form and social links
6. **Footer** - Copyright information

## Getting Started

### Install Dependencies

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

### Production Build

```bash
npm run build
```

The build artifacts will be stored in the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```
